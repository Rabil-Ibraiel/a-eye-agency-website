# A-Eye Brand Guidelines

## Quick reference

| Element | Specification |
| --- | --- |
| Brand mark | `public/brand/a-eye-logo.png` |
| Black | `#000000` |
| White | `#FFFFFF` |
| A-Eye Red | `#FF3B01` |
| Primary typeface | Alfabet |
| Fallback stack | Helvetica Neue, Helvetica, Arial, sans-serif |

## Identity

The A-Eye mark is the primary identifier. Keep its original proportions and
red color. On dark interfaces, the transparent PNG may sit directly on black.
Do not recolor, distort, rotate, outline, or place the mark inside a decorative
container.

## Color

Black and white carry the layout. A-Eye Red is a signal rather than a general
surface color. Use it for the logo, selected states, primary calls to action,
focus, and a small number of authored motion cues.

## Typography

Use Alfabet across display, body, and interface copy. Production deployment
requires licensed webfont files. Until those files are supplied, the website
requests a locally installed copy of Alfabet and falls back to the approved
system sans-serif stack.
